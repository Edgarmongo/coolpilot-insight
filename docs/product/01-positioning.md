# CoolPilot Insight · 产品定位与能力矩阵

> **AI 驱动的多平台内容洞察与智能获客系统**
> AI-Powered Social Intelligence & Lead Generation

## 1. 产品使命

从短视频、社交媒体和公开互联网信息中发现用户需求，通过 AI 识别潜在客户、分析购买意向，
并将有效需求转化为可跟进的销售线索。

核心链路：

```
数据采集  →  需求识别  →  用户画像  →  线索评分  →  客户转化
```

一句话区分：**这不是一个"评论分析工具"，而是一个"从公开内容里找出谁可能需要我的产品"的系统。**
评论分析只是链路的第一个环节。

## 2. 目标客户

首期面向**个人消费者**，而非 MES/ERP 等企业采购客户。四条产品线：

| 产品线 | 目标用户 | 典型需求表达 |
|---|---|---|
| 技术课程 | 技术初学者、开发者 | "想系统学 Java AI" |
| 知识付费 | 有持续学习需求的人 | "有没有完整的 RAG 专栏" |
| 技术资源 | 开发者、学生 | "有没有项目源码和部署文档" |
| 技术服务 | 有具体技术问题的人 | "能不能帮忙部署、排查问题" |

典型场景：用户在抖音评论「想学 RAG，但是不知道从哪里开始」，
系统识别为 `TECH_LEARNING / RAG`，判断购买阶段，匹配「Java RAG 专栏」，
形成候选线索并进入人工审核。

## 3. 数据来源

| 来源 | 采集内容 | 首期状态 |
|---|---|---|
| 抖音 | 视频、公开评论、作者公开信息、话题 | **已实现**（评论链路已验证） |
| 小红书 | 公开笔记、评论、话题、作者信息 | 规划 |
| 快手 | 公开作品、评论、作者信息 | 规划 |
| 公开互联网 | 技术论坛、博客、问答、公开需求页面 | 规划 |

每个来源应有独立 Adapter 与**能力状态**（Available / Limited / Manual / Disabled / Pending）。
「某开源采集器能跑」不等于「该接入方式符合平台规则」——每个平台需单独验证授权范围与访问边界。

## 4. 业务闭环（八大中心）

| 中心 | 职责 | 当前实现度 |
|---|---|---|
| 01 数据源中心 | 平台管理、账号授权、连接器、采集能力 | ❌ 未实现（平台写死在代码里） |
| 02 采集任务中心 | 任务、执行记录、调度、失败重试、归档 | ✅ 已实现（单平台） |
| 03 内容洞察中心 | 内容/评论/作者、搜索、标签、趋势 | ◐ 仅抖音内容与评论 |
| 04 AI 分析中心 | 需求分类、意图识别、阶段判断、线索评分、产品匹配 | ◐ 有分析与证据链，缺线索评分与产品匹配 |
| 05 智能线索中心 | 线索池、证据链、审核、分级、跟进、转化 | ❌ 未实现 |
| 06 运营分析中心 | 渠道效果、需求趋势、转化漏斗、获客成本 | ◐ 仅表层统计 |
| 07 AI 基础平台 | 模型网关、Prompt、Embedding、Rerank、评测 | ❌ 未实现（provider 硬编码） |
| 08 系统管理平台 | 用户、角色、权限、日志、配置、数据保留 | ◐ 权限仅一个 role 字段 |

> 实现度的判定依据见 `docs/audit/`（只读审计，含源码路径与表结构证据）。
> 粗略估算：目标架构覆盖约 **40%**，且缺口集中在三个"加页面解决不了"的地方
> ——多平台抽象、线索域、AI 底座。

## 5. 分阶段路线

| 阶段 | 目标 | 交付物 |
|---|---|---|
| P0 | 仓库审计与基线确认 | `docs/audit/` 六篇（**已完成**） |

## 6. 产品边界（首期明确不做）

- 不做广告主与创作者之间的推广交易市场
- 不做多创作者入驻与分账
- 不做全网无边界爬虫
- 不做批量私信、自动加好友、自动营销
- 不做个人电话号码、私人联系方式的批量搜集
- 不做完整 CRM 替代品

**只做好一件事**：从公开内容中发现真实需求，帮助经营者获得有效客户。

## 7. 合规红线（写进实现约束）

- 只使用符合平台条款、授权范围与适用法律的接入方式
- 不绕过登录限制、验证码、反爬措施与访问控制
- 采集内容必须记录来源 URL、采集时间、采集方式
- 对个人资料实行最小化、脱敏、访问控制与删除机制
- AI 不得推断或输出敏感个人属性作为获客标签
- **公开内容里的需求 ≠ 营销许可**：线索必须经人工确认，联系必须有合法渠道与用户意愿

## 8. 与当前代码的关系

需要说清楚的事实：**现有代码只完成了链路第一环的一半**。

- 已完成：抖音评论采集、清洗、AI 分析（评论级 + 视频级）、证据链、人工复核、报告导出
- 未完成：多平台接入、需求到线索的转化、线索管理、产品匹配、转化归因

因此本文档描述的是**目标形态**，不是现状声明。任何对外描述都应区分
「已实现」「部分实现」「规划中」，避免把规划当能力。

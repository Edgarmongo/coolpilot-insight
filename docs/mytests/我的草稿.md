二、最终目标架构

Java 根包：

com.coolpilot.insight

包含 10 个顶层模块：

system：系统管理

source：数据源管理

collection：数据采集

content：内容管理

analysis：AI 内容分析

lead：潜在客户管理

conversion：转化管理

analytics：经营分析

integration：外部系统集成

common：公共基础能力

所有业务模块统一采用：

controller

application

domain

infrastructure

各业务子领域按职责放入对应层。

system 子领域

user、role、permission、organization、tenant、menu、dict、config、log、audit、notification、job、file。

source 子领域

source、account、capability、health。

collection 子领域

task、run、dispatch、execution、retry、policy、scheduler。

content 子领域

content、comment、author、media、normalization、dedup。

analysis 子领域

task、demand、intent、tag、scoring、profile、prompt、evaluation。

lead 子领域

lead、signal、evidence、scoring、review、followup、lifecycle。

conversion 子领域

product、order、conversion、attribution、lifecycle。

analytics 子领域

dashboard、metrics、dimensions、indicators、report、aggregation。

integration 子领域

collection、ai、coolskyai、connection、credential、contract、client、adapter。

common 子领域

config、constant、enums、exception、response、context、security、audit、pagination、validation、serialization、util、annotation。

上述为目标领域范围，不代表现有项目已经实现这些功能。必须以源码审计结果为依据，区分现状和目标。
